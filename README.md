# 跃迁王国 · 星辉闯关

《HopRealm: Starlight Run》是一款原创像素横版动作肉鸽。探索青苔菌谷、幽光水晶工坊和云端星辉堡垒，在每世界的第四个节点挑战守关首领。拉旗后选择遗物，组合踩踏、砖块、火球龟壳与金币四类羁绊。

## 本地运行

```sh
npm ci
npm run dev
```

打开 Vite 显示的本地地址。游戏使用 TypeScript 与 Canvas 2D，画面和音频由代码生成，星币和天赋存于当前浏览器的 `localStorage`。

| 操作 | 按键 |
| --- | --- |
| 移动 | `A` / `D` 或左右方向键 |
| 跳跃 / 高弹踩踏 | `Space`、`W`、`Z` 或上方向键 |
| 疾跑 | `Shift` |
| 技能 | `J` 或 `X` |
| 下蹲 / 下砸 | `S` 或下方向键 |
| 菜单选择 | 方向键与 `Enter`，也可点击 |
| 构筑与暂停 | `Esc`、`Tab` 或 `P` |
| 静音 | `M` |

手机和平板在闯关时显示触屏按钮。默认可选工匠·里奥。结算获得的星币可解锁其他旅人和永久天赋，通关后可以开启星辉热度。

## 检查与构建

```sh
npx tsc --noEmit
npm run check:levels
npm run build
```

关卡检查用固定种子生成 30 张地图，覆盖三个世界与精英环境词条，并用固定步长碰撞模拟搜索从起点到旗杆的基础跳跃路线。产物位于 `dist/`。
